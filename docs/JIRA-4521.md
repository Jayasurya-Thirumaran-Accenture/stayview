## Summary

Redesign the Room Listing page (`/rooms`) to match the updated Figma design. The new layout introduces a card grid with larger imagery, an enhanced filter experience with amenity-based filtering, and visual indicators for loyalty point earnings. The redesign must be gated behind a feature flag (`room-listing-v2`) so the existing page remains available as a fallback.

## Acceptance Criteria

- [ ] **AC-1:** New room cards display larger hero images (16:9 aspect ratio) with a gradient overlay showing the room name and starting price
- [ ] **AC-2:** Each card shows an amenity icon row (max 5 icons) instead of text badges
- [ ] **AC-3:** A new "Amenities" multi-select filter is added to FilterBar allowing guests to filter by specific amenities (e.g., ocean-view, pet-friendly, spa)
- [ ] **AC-4:** Loyalty points estimate badge appears on each card: "Earn ~{points} points" calculated as `pricePerNight * 10`
- [ ] **AC-5:** "Sold Out" rooms display a muted card style with a waitlist CTA instead of being hidden
- [ ] **AC-6:** The entire redesign is behind feature flag `room-listing-v2` using the existing `isFeatureEnabled()` utility
- [ ] **AC-7:** All existing analytics events continue to fire; new events added:
  - `room_listing_amenity_filter_click` — when an amenity filter is toggled
  - `room_listing_loyalty_badge_hover` — when a user hovers over the points badge
  - `room_listing_waitlist_click` — when a user clicks the waitlist CTA on a sold-out room
- [ ] **AC-8:** Existing E2E tests remain green for the old design; new E2E tests cover the redesigned page behind the feature flag
- [ ] **AC-9:** Unit tests cover: RoomCardV2 rendering, amenity filter logic, loyalty points calculation, feature flag toggle
- [ ] **AC-10:** No regression in Core Web Vitals (LCP < 2.5s, CLS < 0.1, INP < 200ms)

## Design

Figma: link the frame URL in `docs/workshop-config.json` — fetch with **Figma MCP**

Key visual changes:
- Cards use a 16:9 hero image with bottom gradient overlay
- Room name and price overlay the bottom of the image
- Amenity icons replace text badges (use simple SVG icons)
- Loyalty points badge: amber background, positioned top-right of card
- Sold-out cards: 60% opacity with centered "Join Waitlist" button overlay
- Filter bar gains a multi-select amenity dropdown with checkboxes

## Technical Notes

- The feature flag `room-listing-v2` does NOT exist yet — it must be added to `lib/feature-flags.ts`
- Reuse the existing `StarRating` and `PriceTag` components
- The new `RoomCardV2` component should be a separate file, not a modification of `RoomCard`
- Amenity filter logic should extend the existing `filterRooms()` function in `lib/rooms.ts` (which already supports amenity filtering)
- Analytics must follow the `{page}_{element}_{action}` naming convention
